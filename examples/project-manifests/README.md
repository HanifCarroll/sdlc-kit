# Project Manifest Examples

These examples show common `.sdlc/project.yml` shapes. Copy the relevant fields into a repo and adjust project names, commands, path mappings, and smoke paths to match the real project.

- `vercel.yml`: GitHub issue flow with Portless local QA, Vercel previews, and production closeout.
- `cloudflare.yml`: GitHub issue flow with Cloudflare preview separation.
- `local-only.yml`: Local project with no GitHub or remote preview requirement.
